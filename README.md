# ☁️ Serverless CI/CD for Image Processing

## 📌 Overview
This project demonstrates how to build a serverless image processing system with a fully automated CI/CD pipeline.  
When a new image is uploaded to an AWS S3 bucket, a Lambda function is triggered to process the image automatically.  
Infrastructure is managed using Terraform, and deployments are handled with GitHub Action, ensuring that every code change is tested and deployed without manual steps.  

---

## 🎯 Goal
- Automate image processing using serverless architecture.  
- Eliminate manual deployments with CI/CD automation.  
- Ensure scalable and cost-efficient cloud infrastructure.  

---

## 🚀 Features
- AWS Lambda: Handles image processing tasks (resize, compress, transform).  
- Amazon S3: Stores uploaded and processed images.  
- Terraform: Defines and provisions cloud infrastructure as code.  
- GitHub Actions: Runs automated tests and deploys Lambda code on every push.  
- CI/CD Pipeline: Ensures zero manual intervention for deployments.  

---

## ⚙️ Tech Stack
- Languages: Python  
- Cloud: AWS Lambda, Amazon S3  
- Infrastructure: Terraform  
- CI/CD: GitHub Actions  
- Tools: Docker, Git  

---

## 📊 Results

- Fully automated pipeline with no manual deployment required.

- Instant image processing when files are uploaded to S3.

- Infrastructure managed and versioned with Terraform.

---

## ✨ Conclusion

This project highlights how serverless computing + CI/CD automation can streamline cloud deployments and reduce operational overhead, while delivering a scalable and cost-efficient image processing system.
